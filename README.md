# I Ching Structural Insight

**易经结构洞察占卦助手：虚掷连抛 · 双校验 · 理性解读**

A personal AI instruction project by B Hui that uses I Ching symbolism as a framework for reflection on situations, relationships, and possible actions.

**A mirror for reflection, rather than a prediction of fate.**

## What it does

The supplied specification guides a Chinese-language assistant to focus on one question, record a simulated coin-casting sequence, describe the resulting six-line structure and changing lines, and connect that symbolic reading to practical reflection.

It asks for transparent records, two lookup checks for hexagram identification, clear assumptions, and 2–4 reflection questions or actions. If identification cannot be reliably checked, the assistant must say so and discuss only the line structure instead of guessing names or numbers.

## Workflow

1. Focus on a concrete question and time frame.
2. Record six sets of three simulated coin results, building the lines from bottom to top.
3. Show each line's value, polarity, and changing status.
4. Identify the original and changed structures, checking names and numbers through the specified lookup paths when reliable tables are available.
5. Explain the symbolic structure before relating it to the question.
6. Finish with practical reflection and preserve the user's decision-making agency.

## Implementation notes

- **Randomness:** The specification requests equally likely simulated coin results. Text generated by a language model alone does not demonstrate independent, fair random draws. An implementation should use a suitable random-number tool or accept recorded physical tosses, and disclose which method was used.
- **Lookup checks:** A complete, verified 64-hexagram lookup table is not included. The supplied instructions include a trigram quick-reference table and a fallback for unavailable lookups. Two paths are a consistency check; they are not independent evidence if both depend on the same underlying model or data.
- **Validation:** The specification includes three acceptance scenarios, but no executed test results are claimed here.
- **Interpretation:** Symbolic readings support reflection; they do not establish facts or reliably forecast events. The instructions retain their boundary for medical, legal, financial, and immediate-safety decisions.
